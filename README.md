# Amazon Homepage Clone

A static replica of the Amazon.com homepage built with **HTML5** and **CSS3**. This project recreates the look and feel of the Amazon landing page for learning and frontend design practice purposes.

## 🚀 Features

    - Responsive top navigation bar with:
    - Amazon logo
    - Delivery location
    - Search bar
    - Account, Orders, and Cart options
    - Hero section with promotional banner
    - Shop section with 8 product categories and images
    - Multi-column footer with useful links
    - Bottom footer with copyright

---

## 🛠️ Technologies Used

    - **HTML5** – For page structure and semantic layout
    - **CSS3** – For styling, layout (Flexbox), and hover effects
    - **Font Awesome** – For cart and location icons

---

## 🧾 Notes
    This is a static website. No backend or interactivity is implemented.

    Images used are locally stored. Ensure all image paths match your project directory.

    Designed primarily for desktop view. Basic responsiveness only.
